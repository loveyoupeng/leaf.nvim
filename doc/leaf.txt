*leaf.txt*  Markdown preview via the leaf CLI                 *leaf*

==============================================================================
INTRODUCTION                                                        *leaf-intro*

leaf.nvim renders Markdown inside Neovim using the `leaf` binary
(https://github.com/RivoLink/leaf). The Viewer — the window showing rendered
output — runs in one of two Modes:

- Static:       one-shot `leaf --inline` output piped into a terminal buffer
- Interactive:  the leaf TUI running live via |termopen()|

and one of four Placements:

- Window: the render takes over the content window like a normal |:edit|
          (the previously visited window when invoked from an explorer
          sidebar) as a listed, named buffer (`leaf://<file>`); closing
          swaps the displaced buffer back in, switching that window to
          another buffer closes the Viewer, and a file the explorer opens
          around the terminal host folds back into the taken-over window
          instead of leaving a spare split
- Split:  vertical split right of the invoking window
- Float:  centered floating window (opt-in only, never the default)
- Tab:    new tabpage holding only the render; closing the Viewer closes
          the tab and returns to the previously active one

Editing stays in the normal buffer. The Viewer refreshes on |:write| —
Static re-renders whenever the source path is written, by any buffer
(including unsaved content of the current buffer); Interactive tracks the
on-disk file with leaf's `--watch`.

Requires Neovim >= 0.10 and the `leaf` binary on $PATH (or |leaf.setup()|
`leaf_path`). A Markdown Picker needs fzf-lua. Reading the file under the
cursor needs neo-tree.nvim.

==============================================================================
COMMANDS                                                        *leaf-commands*

:Leaf[!] [file]                                                        *:Leaf*
        Toggle the Viewer. Viewers are per-window and coexist. A bare
        :Leaf closes the focused window's Viewer, or the Viewer showing
        the focused buffer; others stay open. An explicit [file] always
        means "show this": it replaces only the focused window's Viewer.

        Source resolution, in order:
        1. [file] — preview that file. Naming the current buffer's file
           keeps buffer semantics (unsaved content in Static Mode).
        2. No [file], Markdown buffer focused — preview that buffer.
        3. No [file], focus in a neo-tree panel — preview the file under
           the cursor; a non-Markdown file or a directory errors.
        4. Nothing inferable — open the Picker.

        Placement under the default position = "auto": Split for a buffer
        source (1/2 above), Window for a file source (1/3/4): the render
        takes over the content window (the previously visited window when
        invoked from an explorer sidebar) without disturbing the layout;
        closing restores the displaced buffer.

        Bang flips the configured default Mode: with interactive = false,
        :Leaf! opens leaf's TUI with --watch. Interactive Mode needs the
        file on disk; a never-saved buffer errors.

        Inside a Static Viewer: q or <Esc> closes; j/k, <C-d>/<C-u> and
        the mouse wheel scroll the render (a terminal buffer with full
        scrollback). Inside an Interactive Viewer: the wheel scrolls too —
        leaf.nvim forwards it as arrow keys, since Neovim does not forward
        wheel events to mouse-capturing terminal jobs (see
        leaf-config `scroll_lines` for the step); leaf's own quit key
        exits. No plugin keys shadow your bindings: use the native
        <C-\><C-n> to leave terminal mode, then q or <Esc> closes.

        Both modes show a one-line key hint in the winbar; disable with
        `show_hints = false`.

The Picker has no standalone command: it opens as the |:Leaf| fallback
when nothing is inferable. It lists Markdown files under the current
working directory with a leaf-rendered preview pane; selecting an entry
opens it in a Viewer (default Mode, Window placement under "auto").

SETUP                                                              *leaf-setup*

require("leaf").setup({}) ~
  leaf_path                  string?   leaf binary; nil = $PATH lookup
  interactive                boolean   default Mode                     false
  position                   string    "auto"|"window"|"split"|"float"|"tab"
                                                                 "auto"
  theme                      string?   leaf --theme value
  border                     string    Float border                   "rounded"
  width_ratio                number    Float width ratio                  0.7
  height_ratio               number    Float height ratio                 0.7
  split_ratio                number    Split width ratio                  0.5
  scroll_lines               number    Lines per wheel notch, Interactive    3
  show_hints                 boolean   Key hints in the Viewer's winbar   true
  markdown_filetypes         string[]  filetypes treated as Markdown
  markdown_extensions        string[]  extensions treated as Markdown

==============================================================================
HEALTH                                                            *leaf-health*

|:checkhealth| leaf reports the resolved binary and its version, and
whether fzf-lua (the Picker) is available.
