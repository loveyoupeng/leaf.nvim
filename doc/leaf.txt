*leaf.txt*  Markdown preview via the leaf CLI                 *leaf*

==============================================================================
INTRODUCTION                                                        *leaf-intro*

leaf.nvim renders Markdown inside Neovim using the `leaf` binary
(https://github.com/RivoLink/leaf). The Viewer — the window showing rendered
output — runs in one of two Modes:

- Static:       one-shot `leaf --inline` output piped into a terminal buffer
- Interactive:  the leaf TUI running live via |termopen()|

and one of two Placements:

- Split:  vertical split right of the source buffer
- Float:  centered floating window

Editing stays in the normal buffer. The Viewer refreshes on |:write| —
Static re-renders from the buffer (including unsaved content); Interactive
tracks the on-disk file with leaf's `--watch`.

Requires Neovim >= 0.10 and the `leaf` binary on $PATH (or |leaf.setup()|
`leaf_path`). A Markdown Picker needs telescope.nvim or fzf-lua.

==============================================================================
COMMANDS                                                        *leaf-commands*

:Leaf[!] [file]                                                        *:Leaf*
        Toggle the Viewer. An open Viewer closes regardless of arguments.

        Without [file] and with a Markdown buffer: preview that buffer.
        With [file]: preview that file (Placement is Float). Naming the
        current buffer's file keeps buffer semantics.

        Without [file] on a non-Markdown buffer: open the Picker.

        Bang flips the configured default Mode: with interactive = false,
        :Leaf! opens leaf's TUI with --watch. Interactive Mode needs the
        file on disk; a never-saved buffer errors.

        Inside a Static Viewer: q or <Esc> closes. Inside an Interactive
        Viewer: leaf's own quit key exits; <C-\> force-closes.

:Telescope leaf                                              *leaf-telescope*
        Picker over Markdown files under the project root with a
        leaf-rendered preview pane (telescope backend). Selecting an entry
        opens it in a Viewer (default Mode, Float placement). With fzf-lua
        installed instead, the Picker uses it automatically; no separate
        command is needed.

==============================================================================
SETUP                                                              *leaf-setup*

require("leaf").setup({}) ~
  leaf_path                  string?   leaf binary; nil = $PATH lookup
  interactive                boolean   default Mode                     false
  position                   string    "auto" | "split" | "float"       "auto"
  theme                      string?   leaf --theme value
  border                     string    Float border                   "rounded"
  width_ratio                number    Float width ratio                  0.7
  height_ratio               number    Float height ratio                 0.7
  split_ratio                number    Split width ratio                  0.5
  markdown_filetypes         string[]  filetypes treated as Markdown
  markdown_extensions        string[]  extensions treated as Markdown

==============================================================================
HEALTH                                                            *leaf-health*

|:checkhealth| leaf reports the resolved binary and its version, and which
picker backend (telescope.nvim or fzf-lua) is available.
